# 🏛️ Central da Comunidade Los Trouxas Dev

Bem-vindo ao repositório central da nossa organização! Este espaço serve como a "Fonte da Verdade" para as nossas diretrizes, normas de conduta e documentação global.

---

## 🎯 Objetivo
Este repositório centraliza a governança da comunidade no GitHub. Ele foi criado para garantir que todos os membros, desde iniciantes a seniores, saibam como colaborar de forma eficiente e respeitosa em qualquer projeto da organização.

## 📁 Documentos Principais
Para garantir uma boa experiência na comunidade, consulte os ficheiros abaixo:

* 🚀 **[Guia de Contribuição](./CONTRIBUTING.md)**: Aprenda o passo a passo para enviar Pull Requests, reportar bugs e sugerir funcionalidades.
* ⚖️ **Código de Conduta**: Regras básicas de convivência para manter o nosso ambiente saudável e inclusivo.
* 💬 **Aba de Discussões**: O local ideal para brainstorming, dúvidas rápidas e anúncios da comunidade.

## 🚀 Como começar a colaborar?
1. **Fork & Clone**: Escolha um dos nossos projetos ativos e faça um fork.
2. **Leia o CONTRIBUTING**: Certifique-se de que entende os padrões de commit e branch.
3. **Interaja no Discord**: O alinhamento técnico acontece primeiro na nossa comunidade.

## ☕ Sobre o Los Trouxas Dev
Somos uma comunidade apaixonada por tecnologia que acredita no poder do **Open Source**. O nosso foco é o desenvolvimento **Full-stack** (Front-end & Back-end), onde transformamos café em soluções reais.
