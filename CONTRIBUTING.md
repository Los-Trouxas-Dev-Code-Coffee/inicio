# Guia de Contribuição 🚀

Primeiramente, obrigado por te interessares em contribuir para o **Los Trouxas Dev | Code & Coffee**! É a colaboração de pessoas como tu que faz a nossa comunidade crescer.

## 1. Código de Conduta
Ao participares, concordas em manter um ambiente respeitoso, inclusivo e livre de assédio. O foco é a aprendizagem mútua.

## 2. Como Contribuir?
- **Reportar Bugs:** Abre uma *Issue* com detalhes do erro e como reproduzi-lo.
- **Sugerir Melhorias:** Partilha ideias na aba *Discussions*.
- **Documentação:** Melhora os ficheiros README ou manuais.
- **Enviar Código:** Resolve Issues ou implementa novas funcionalidades.

## 3. Passo a Passo para Pull Requests
1. Faz **Fork** do projeto.
2. Cria uma branch: `git checkout -b feature/nome-da-feature`.
3. Commita as alterações: `git commit -m "feat: descrição da alteração"`.
4. Faz o push: `git push origin feature/nome-da-feature`.
5. Abre um **Pull Request**.

## 4. Padrões Sugeridos
- Mensagens de commit claras e semânticas (ex: `feat:`, `fix:`, `docs:`).
- Código limpo e, preferencialmente, comentado em Português.
- Seguir as regras de linting/estilo do repositório.
